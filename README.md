# VoidWare v2 [COMPLETE + Discord Webhooker]

Advanced Roblox client-side exploit UI built on WindUI.

## Features
- Full movement suite (Air Strafe, Pixel Surf, Virtual Strafe, Easy Bounce, Auto Trimp, Downed Dash, etc.)
- Player / Visuals / Fun / Misc / Utility systems
- **New Discord Webhooker tab**
  - Textbox for webhook URL
  - Apply Discord Webhook button
  - Test button
  - Detection System: automatically logs every major feature toggle to your Discord channel with rich embeds (player name, UserId, feature, status, game, timestamp)

## Usage
1. Execute the script in your preferred executor.
2. Go to the **Discord Webhooker** tab.
3. Paste your Discord webhook URL.
4. Click **Apply Discord Webhook**.
5. (Optional) Enable **Detection System** so every toggle is logged.
6. Click **Test** to verify the webhook works.
